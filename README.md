# StackOverflow Knowledge Network

Looking at StackOverflow like it's a giant classroom: who helps who, and what kind of questions people ask.

## What I'll be doing
1. Pull questions and answers from the Stack Exchange API
2. Build a directed graph of who answers whom
3. Compute in-degree, out-degree, hub, and authority scores
4. Label each question using Bloom's taxonomy and see which levels get answered by who

## Libraries
requests, pandas, networkx, matplotlib, beautifulsoup4, nltk
